# 한자 급수 학습 사이트 하네스

## Purpose

원본 한자 자료를 신뢰할 수 있는 급수별 데이터로 정리하고, 엄마와 윤우가 각기 다른 방식으로 연습할 수 있는 안전하고 검증된 학습 사이트를 만든다.

## Pattern

Pipeline + producer-reviewer. 원본 자료 정리, 학습 경험 설계, 구현은 앞 단계의 결정에 의존하며, 데이터와 권한은 독립적으로 검토해야 한다.

## Product rules

- 첫 화면에서 학습자 `엄마` 또는 `윤우`를 선택한다.
- 급수 선택 후 해당 급수의 한자를 무작위 순서로 보여 준다.
- 엄마 모드에는 한자와 뜻·음이 함께 보인다.
- 윤우 모드에는 한자만 보인다.
- 급수 전환과 급수 내 랜덤 새로고침은 엄마 모드에서만 제공한다.
- 한자 원본은 `01 raw data/`에 보관한다. 원본을 수정하지 않고, 추출·정제 결과와 근거를 남긴다.

## Roles and outputs

| Role | Owns | Output | Depends on |
|---|---|---|---|
| source-curator | PDF 원본 추출, 급수·한자·뜻음 정규화, 누락 검수 | `docs/data-catalog.md`, `supabase/seed/` | `01 raw data/` |
| learning-designer | 학습자별 화면·행동·상태·예외 흐름 기획 | `docs/product-spec.md` | 제품 규칙, 데이터 카탈로그 |
| app-builder | Supabase 스키마/RLS와 웹 앱 구현 | `supabase/migrations/`, 앱 소스 | 승인된 기획과 데이터 계약 |
| quality-reviewer | 데이터 무결성, 권한 분리, 랜덤화, UI 회귀 검토 | `docs/verification-report.md` | 구현물과 원본 근거 |

주 담당 에이전트는 범위 조정, 단계 간 의사결정, 통합 및 최종 사용자 소통을 맡는다.

## Runbook

1. 기존 자료를 확인하고 작업을 신규·확장·유지보수로 분류한다.
2. `source-curator`가 원본 페이지 근거를 포함한 데이터 계약을 만든다. 불명확한 글자는 추정하지 말고 검토 대상으로 표시한다.
3. `learning-designer`가 엄마/윤우 모드, 급수 선택, 카드 진행, 랜덤 새로고침, 빈 급수와 오류 상태를 기획한다.
4. `app-builder`가 승인된 계약에 따라 Supabase 테이블·마이그레이션·시드·RLS와 화면을 구현한다.
5. `quality-reviewer`가 원본 대조, 급수별 개수, 중복, 뜻음 노출, 엄마 전용 제어, 새로고침의 순열성을 점검한다.
6. 주 담당 에이전트가 결과를 통합하고, 미확정 원본/권한 방식/배포 환경은 사용자에게 명확히 남긴다.

## Collaboration rules

- 병렬 작업은 서로 다른 산출물과 의사결정에만 적용한다. 데이터 계약이 확정되기 전에는 시드 데이터나 스키마를 확정하지 않는다.
- 각 역할은 변경 파일, 가정, 실행한 검증, 남은 위험을 짧게 보고한다.
- 임시 조사 자료는 `.codex/harness/_workspace/<phase>-<role>-<artifact>.<ext>`에 둔다. 최종 문서는 `docs/`, DB 산출물은 `supabase/`에 둔다.
- 원본 PDF와 사용자 변경 사항은 덮어쓰지 않는다.

## Acceptance criteria

- 원본의 각 한자는 출처 페이지와 급수에 연결된다.
- 급수별 한자 수와 중복 여부를 자동 검증할 수 있다.
- 윤우 화면/응답에는 뜻·음과 엄마용 제어가 포함되지 않는다.
- 엄마의 랜덤 새로고침은 선택 급수의 모든 한자를 한 번씩 포함한 새 순서를 만든다.
- Supabase 공개 키만으로 데이터 변경 또는 엄마 기능 우회가 되지 않도록 RLS와 권한 모델이 검증된다.

## Failure policy

제한된 작업 실패 시 한 번 재시도한다. 두 번째 실패 후에는 근거를 보존하고 부분 결과임을 표시한다. 원본 판독 불가, 권한 정책 선택, 배포 계정·비밀값처럼 결과를 바꾸는 항목은 사용자 결정을 요청한다.
